Stellt die internen Daten eines Grafikcontainers dar. Diese Klasse wird verwendet, wenn der Zustand eines [Graphics](../../com.aspose.drawing/graphics)-Objekts mithilfe der Methoden [Graphics.beginContainer](../../com.aspose.drawing/graphics\#beginContainer) und [Graphics.endContainer(GraphicsContainer)](../../com.aspose.drawing/graphics\#endContainer-GraphicsContainer-) gespeichert wird. Diese Klasse kann nicht vererbt werden.
