Gibt an, wie die Quellfarben mit den Hintergrundfarben kombiniert werden.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [SourceOver](#SourceOver) | Gibt an, dass beim Rendern einer Farbe diese mit der Hintergrundfarbe gemischt wird. |
| [SourceCopy](#SourceCopy) | Gibt an, dass beim Rendern einer Farbe diese die Hintergrundfarbe überschreibt. |
### SourceOver {#SourceOver}
```
public static final int SourceOver
```


Gibt an, dass beim Rendern einer Farbe diese mit der Hintergrundfarbe gemischt wird. Die Mischung wird durch die Alpha-Komponente der gerenderten Farbe bestimmt.

### SourceCopy {#SourceCopy}
```
public static final int SourceCopy
```


Gibt an, dass beim Rendern einer Farbe diese die Hintergrundfarbe überschreibt.
