### SourceOver {#SourceOver}
```
public static final int SourceOver
```


Especifica que cuando se renderiza un color, se mezcla con el color de fondo. La mezcla se determina por el componente alfa del color que se está renderizando.

### SourceCopy {#SourceCopy}
```
public static final int SourceCopy
```


Especifica que cuando se renderiza un color, sobrescribe el color de fondo.
