Define un mapa para convertir colores. Varios métodos de la clase [ImageAttributes](../../com.aspose.drawing.imaging/imageattributes) ajustan los colores de la imagen usando una tabla de remapeo de colores, que es una matriz de estructuras [ColorMap](../../com.aspose.drawing.imaging/colormap). No heredable.
