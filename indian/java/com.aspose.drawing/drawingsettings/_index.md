### getStrictMode() {#getStrictMode--}
```
public static boolean getStrictMode()
```


एक मान प्राप्त करता है जो दर्शाता है कि न लागू की गई सुविधाओं की अधिक कड़ी पकड़ सक्षम है या नहीं।

--------------------

यदि true पर सेट किया जाता है, तो वर्तमान कार्यान्वयन में सही ढंग से काम न करने वाली सुविधाओं/पैरामीटरों का उपयोग करने की स्थिति में लाइब्रेरी NotImplementedException फेंकेगी। यदि false पर सेट किया जाता है, तो कुछ पैरामीटरों को अनदेखा किया जा सकता है ताकि उपयोगकर्ता प्रोग्राम को काम करने का मौका मिल सके। ऐसे में ड्राइंग परिणाम GDI+ की तुलना में अलग दिख सकते हैं।

**Returns:**
boolean - एक मान जो दर्शाता है कि न लागू की गई सुविधाओं की अधिक कड़ी पकड़ सक्षम है या नहीं।
