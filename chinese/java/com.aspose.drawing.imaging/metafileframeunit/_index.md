指定用于确定元文件大小和位置的矩形的计量单位。此单位在创建 [Metafile](../../com.aspose.drawing.imaging/metafile) 对象时指定。
## 字段

| 字段 | 描述 |
| --- | --- |
| [Pixel](#Pixel) | 计量单位为 1 像素。 |
| [Point](#Point) | 计量单位为 1 打印点。 |
| [Inch](#Inch) | 计量单位为 1 英寸。 |
| [Document](#Document) | 计量单位为 1/300 英寸。 |
| [Millimeter](#Millimeter) | 计量单位为 1 毫米。 |
| [GdiCompatible](#GdiCompatible) | 计量单位为 0.01 毫米。 |
