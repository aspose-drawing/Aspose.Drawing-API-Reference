Spécifie comment les couleurs source sont combinées avec les couleurs d'arrière-plan.
## Champs

| Champ | Description |
| --- | --- |
| [SourceOver](#SourceOver) | Spécifie que lorsqu'une couleur est rendue, elle est mélangée avec la couleur d'arrière-plan. |
| [SourceCopy](#SourceCopy) | Spécifie que lorsqu'une couleur est rendue, elle écrase la couleur d'arrière-plan. |
### SourceOver {#SourceOver}
```
public static final int SourceOver
```


Spécifie que lorsqu'une couleur est rendue, elle est mélangée avec la couleur d'arrière-plan. Le mélange est déterminé par le composant alpha de la couleur rendue.

### SourceCopy {#SourceCopy}
```
public static final int SourceCopy
```


Spécifie que lorsqu'une couleur est rendue, elle écrase la couleur d'arrière-plan.
