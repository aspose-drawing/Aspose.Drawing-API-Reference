Représente les données internes d'un conteneur graphique. Cette classe est utilisée lors de la sauvegarde de l'état d'un objet [Graphics](../../com.aspose.drawing/graphics) en utilisant les méthodes [Graphics.beginContainer](../../com.aspose.drawing/graphics\#beginContainer) et [Graphics.endContainer(GraphicsContainer)](../../com.aspose.drawing/graphics\#endContainer-GraphicsContainer-). Cette classe ne peut pas être héritée.
