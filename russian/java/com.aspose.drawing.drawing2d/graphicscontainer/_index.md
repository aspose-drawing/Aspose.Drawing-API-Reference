Представляет внутренние данные графического контейнера. Этот класс используется при сохранении состояния объекта [Graphics](../../com.aspose.drawing/graphics) с помощью методов [Graphics.beginContainer](../../com.aspose.drawing/graphics\#beginContainer) и [Graphics.endContainer(GraphicsContainer)](../../com.aspose.drawing/graphics\#endContainer-GraphicsContainer-). Этот класс не может быть наследован.
