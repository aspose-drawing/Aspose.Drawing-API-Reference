Definisce una mappa per la conversione dei colori. Diversi metodi della classe [ImageAttributes](../../com.aspose.drawing.imaging/imageattributes) regolano i colori dell'immagine utilizzando una tabella di rimappatura dei colori, che è un array di strutture [ColorMap](../../com.aspose.drawing.imaging/colormap). Non ereditabile.
