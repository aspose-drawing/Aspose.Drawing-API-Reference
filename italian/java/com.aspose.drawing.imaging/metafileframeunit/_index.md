Specifica l'unità di misura per il rettangolo usato per dimensionare e posizionare un metafile. Questo è specificato durante la creazione dell'oggetto [Metafile](../../com.aspose.drawing.imaging/metafile).
## Campi

| Campo | Descrizione |
| --- | --- |
| [Pixel](#Pixel) | L'unità di misura è 1 pixel. |
| [Point](#Point) | L'unità di misura è 1 punto di stampa. |
| [Inch](#Inch) | L'unità di misura è 1 pollice. |
| [Document](#Document) | L'unità di misura è 1/300 di pollice. |
| [Millimeter](#Millimeter) | L'unità di misura è 1 millimetro. |
| [GdiCompatible](#GdiCompatible) | L'unità di misura è 0,01 millimetro. |
