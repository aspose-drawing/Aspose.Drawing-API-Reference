### getStrictMode() {#getStrictMode--}
```
public static boolean getStrictMode()
```


Λαμβάνει μια τιμή που υποδεικνύει εάν είναι ενεργοποιημένο το πιο αυστηρό εντοπισμό μη υλοποιημένων λειτουργιών.

--------------------

Εάν οριστεί σε true, σε περίπτωση χρήσης λειτουργιών/παραμέτρων που δεν λειτουργούν σωστά στην τρέχουσα υλοποίηση, η βιβλιοθήκη θα ρίξει NotImplementedException. Εάν οριστεί σε false, ορισμένες παράμετροι μπορεί να αγνοηθούν ώστε να δοθεί η δυνατότητα στο πρόγραμμα του χρήστη να λειτουργήσει. Σε αυτήν την περίπτωση τα αποτελέσματα του σχεδίου μπορεί να φαίνονται διαφορετικά σε σύγκριση με το GDI+.

**Returns:**
boolean - μια τιμή που υποδεικνύει εάν είναι ενεργοποιημένο το πιο αυστηρό εντοπισμό μη υλοποιημένων λειτουργιών.
