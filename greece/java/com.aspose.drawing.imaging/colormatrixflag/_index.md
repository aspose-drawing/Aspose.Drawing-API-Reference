### SkipGrays {#SkipGrays}

Όλα τα χρώματα προσαρμόζονται, αλλά οι γκρι αποχρώσεις δεν προσαρμόζονται. Μια γκρι απόχρωση είναι οποιοδήποτε χρώμα που έχει την ίδια τιμή για τα κόκκινα, πράσινα και μπλε συστατικά του.
