Καθορίζει τη φύση των εγγραφών που τοποθετούνται σε ένα αρχείο Enhanced Metafile (EMF). Αυτή η απαρίθμηση χρησιμοποιείται από αρκετούς κατασκευαστές στην κλάση [Metafile](../../com.aspose.drawing.imaging/metafile).

### EmfOnly {#EmfOnly}
```
public static final int EmfOnly
```


Καθορίζει ότι όλες οι εγγραφές στο metafile είναι εγγραφές EMF, οι οποίες μπορούν να εμφανιστούν από GDI ή GDI+.

### EmfPlusOnly {#EmfPlusOnly}
```
public static final int EmfPlusOnly
```


Καθορίζει ότι όλες οι εγγραφές στο metafile είναι εγγραφές EMF+, οι οποίες μπορούν να εμφανιστούν από GDI+ αλλά όχι από GDI.

### EmfPlusDual {#EmfPlusDual}
```
public static final int EmfPlusDual
```


Καθορίζει ότι όλες οι εγγραφές EMF+ στο metafile συνδέονται με μια εναλλακτική εγγραφή EMF. Τα metafiles τύπου `EmfType.EmfPlusDual` μπορούν να εμφανιστούν από GDI ή από GDI+.
