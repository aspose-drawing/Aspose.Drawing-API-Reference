### World {#World}
```
public static final int World
```


Καθορίζει ότι οι συντεταγμένες βρίσκονται στο πλαίσιο συντεταγμένων του κόσμου. Οι συντεταγμένες του κόσμου χρησιμοποιούνται σε μη φυσικό περιβάλλον, όπως ένα περιβάλλον μοντελοποίησης.

### Page {#Page}
```
public static final int Page
```


Καθορίζει ότι οι συντεταγμένες βρίσκονται στο πλαίσιο συντεταγμένων της σελίδας. Οι μονάδες τους ορίζονται από την ιδιότητα Graphics.PageUnit και πρέπει να είναι ένα από τα στοιχεία της απαρίθμησης GraphicsUnit.

### Device {#Device}
```
public static final int Device
```


Καθορίζει ότι οι συντεταγμένες βρίσκονται στο πλαίσιο συντεταγμένων της συσκευής. Σε οθόνη υπολογιστή, οι συντεταγμένες της συσκευής συνήθως μετρώνται σε εικονοστοιχεία.
