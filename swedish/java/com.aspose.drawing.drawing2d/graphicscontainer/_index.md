Representerar den interna datan för en grafikbehållare. Denna klass används när tillståndet för ett [Graphics](../../com.aspose.drawing/graphics)-objekt sparas med hjälp av metoderna [Graphics.beginContainer](../../com.aspose.drawing/graphics\#beginContainer) och [Graphics.endContainer(GraphicsContainer)](../../com.aspose.drawing/graphics\#endContainer-GraphicsContainer-). Denna klass kan inte ärvas.
